# 🛫 Дипломный проект QA.GURU: Автоматизация тестирования Aviasales

Данный репозиторий содержит дипломный проект по автоматизации тестирования веб-интерфейса и API сайта [Aviasales](https://www.aviasales.ru/).

> **Примечание:** Мобильная автоматизация (Appium) вынесена в отдельный репозиторий, так как на данный момент нацелена на демонстрацию работы с нативными приложениями (на примере Wikipedia), а не Aviasales.

---

## 🛠 Технологический стек

* **Java 17** — язык программирования
* **Gradle** — сборка проекта и управление зависимостями
* **JUnit 5** — фреймворк для тестирования (используется параметризация `@CsvSource`, `@MethodSource`, `@ValueSource`)
* **Selenide** — автоматизация UI (паттерн **Page Object**)
* **REST Assured** — тестирование API
* **Owner** — управление конфигурацией (чтение `.properties` файлов)
* **Lombok** — генерация геттеров/сеттеров для моделей API
* **AssertJ** — читаемые ассерты
* **Allure Report** — визуализация отчетов, шагов и вложений
* **Jenkins** — CI/CD пайплайн

---

## ✅ Реализованные проверки

### UI (Веб-интерфейс)
В классе `ui.tests.ParameterizedTests` реализованы параметризованные тесты:
1.  **Проверка сервисов:** проверка того, что при клике на "Избранное", "Впечатления", "Авиабилеты" и т.д. на главной странице отображается корректное текстовое описание (параметризация через `@CsvSource`).
2.  **Проверка городов:** проверка, что в выпадающем списке при поиске отелей присутствуют нужные города (Москва, Санкт-Петербург, Сочи, Калининград). Используется `Enum` и `@MethodSource`.
3.  **Проверка навигации:** проверка видимости кнопок навигационной панели (Профиль, Журнал, Поддержка и т.д.).

### API
В классе `api.tests.CountriesTest` реализована проверка:
*   `GET /data/ru/countries.json` — запрос возвращает статус 200, структура ответа валидируется, список стран не пуст.
*   Используется токенизация (передача токена в query-параметрах) и спецификации запросов/ответов.
*   Ответ парсится в POJO-модель `Country` с помощью Jackson.
